Why Bluetooth HID?

The Human Interface Device protocol is the universal standard for input devices. Here's why it matters.

Universal Compatibility

Every modern operating system has built-in HID support. WindPad works everywhere without drivers or configuration.

Ultra-Low Latency

Bluetooth radio operates at hardware level with minimal processing overhead. Response times comparable to physical peripherals.

Secure by Design

Bluetooth pairing establishes encrypted communication. No data leaves the local connection, ensuring privacy.

Zero Network Dependency

Works completely offline. No Wi-Fi required, no router configuration, no firewall issues. Just pair and control.

Under the Hood

WindPad uses Android's BluetoothHidDevice API to register as a HID device.

Kotlin 
// Register WindPad as a Bluetooth HID device
val hidDevice = bluetoothAdapter.getProfileProxy(context, object : BluetoothHidDevice.Callback() {
    override fun onAppStatusChanged(pl: BluetoothHidDevice, registered: Boolean) {
        if (registered) {
            // WindPad is now recognized as a mouse/keyboard
            Log.d("WindPad", "HID device registered successfully")
        }
    }
    
    override fun onConnectionStateChanged(device: BluetoothDevice, state: Int) {
        when (state) {
            BluetoothHidDevice.STATE_CONNECTED -> {
                // Connected to PC - ready to send input
                Log.d("WindPad", "Connected to ${device.name}")
            }
            BluetoothHidDevice.STATE_DISCONNECTED -> {
                // Connection lost
                Log.d("WindPad", "Disconnected from ${device.name}")
            }
        }
    }
}, BluetoothProfile.HID_DEVICE)

// Send mouse movement report
fun sendMouseMove(x: Int, y: Int) {
    val report = byteArrayOf(
        0x01, // Report ID for mouse
        x.toByte(), // X movement
        y.toByte(), // Y movement
        0x00  // Button state
    )
    hidDevice.setReport(hostDevice, REPORT_TYPE_OUTPUT, report)
}
