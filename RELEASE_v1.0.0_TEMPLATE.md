# WindPad v1.0.0 🚀

We are excited to announce the official v1.0.0 release of **WindPad**!

WindPad turns your Android phone into a low-latency, fully functional Bluetooth HID trackpad and keyboard. Because it uses standard Bluetooth Human Interface Device (HID) protocols, the target computer or device recognizes it as a physical mouse and keyboard. **No receiver application is required.**

## ✨ Features included in this release:

- **Bluetooth HID Trackpad** — Precision control tailored for speed and accuracy.
- **Bluetooth HID Keyboard** — Type directly; sends HID keycodes character by character.
- **Multi-touch Gestures** — Support for 1-finger move, 2-finger scroll, pinch-to-zoom, and 3-finger swipe.
- **Quick Action Keys** — Dedicated buttons for Copy, Paste, Cut, Undo, Select All, and Emoji.
- **Smart Clipboard Paste** — Send text directly from your phone's clipboard to your PC.
- **Material Themes** — Beautiful Dark, Light, and System themes for a native Android feel.
- **Optional Windows Helper** — For advanced cursor acceleration and low-pass filtering on Windows systems.

## 📥 Installation

1. Download **`WindPad.apk`** from the Assets below.
2. Install the APK on your Android device.
3. Enable Bluetooth on your target computer (Windows/macOS/Linux) or Smart TV.
4. Pair your Android phone with the target device.
5. Open WindPad and start controlling your device natively!

*(Optional)* Download the Windows Helper source from `windpad-server` if you wish to use the advanced pointer smoothing on Windows.
